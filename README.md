# Afeef Ahmed Jarif Portfolio

A clean, responsive portfolio website for Afeef Ahmed Jarif, QA Automation Engineer, built with Next.js, TypeScript, Tailwind CSS, and the App Router.

## Run Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Open `http://localhost:3000`.

Place `Afeef_Ahmed_CV.pdf` in the `public` folder so the Download CV button works.

## Push To GitHub

1. Initialize git if needed:
   ```bash
   git init
   ```
2. Add and commit the project:
   ```bash
   git add .
   git commit -m "Build portfolio website"
   ```
3. Create a new repository on GitHub.
4. Connect the remote and push:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
   git branch -M main
   git push -u origin main
   ```

## Deploy On Vercel For Free

1. Go to `https://vercel.com` and sign in with GitHub.
2. Click **Add New Project**.
3. Import the GitHub repository.
4. Keep the default framework settings for Next.js.
5. Click **Deploy**.

Vercel will build the site automatically and provide a live URL.
